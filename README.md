# บ็อตรับยศด้วยอิโมจิ — ร้านไอฟิล์ม

สมาชิกกดอิโมจิบนข้อความของบ็อตแล้วได้รับยศที่ผูกไว้ เลือกได้หลายยศ เมื่อเอาอิโมจิออกจะถอดยศนั้น สามารถปิดการถอดยศได้ใน config.json

บ็อตสร้างข้อความพร้อมอิโมจิอัตโนมัติ และเก็บ ID ข้อความไว้ใน data/panel.json เพื่อใช้ข้อความเดิมหลังเปิดใหม่ รองรับอิโมจิทั่วไปและอิโมจิที่สร้างเองในเซิร์ฟเวอร์เดียวกัน

## 1. สร้างบ็อตและเชิญเข้าเซิร์ฟเวอร์

1. เปิด https://discord.com/developers/applications เลือก New Application แล้วตั้งชื่อ
2. ที่หน้า Bot ใช้ Reset Token เพื่อรับ Token แล้วเติมใน .env เฉพาะเครื่องของคุณ เก็บ Token เป็นความลับ
3. ที่ Installation เปิด Guild Install และใช้ scope bot จากนั้นเลือกสิทธิ์ Manage Roles, View Channels, Send Messages, Embed Links, Read Message History และ Add Reactions ใช้ Install Link เพิ่มบ็อตเข้าเซิร์ฟเวอร์ หากใช้ OAuth2 URL Generator ก็เลือก scope bot และสิทธิ์ชุดเดียวกัน
4. ไปที่ Server Settings > Roles แล้วลากยศของบ็อตให้สูงกว่าทุกยศที่ต้องการแจก
5. ให้สมาชิกมองเห็นห้องและอ่านประวัติข้อความได้ เพื่อกดอิโมจิที่บ็อตวางไว้

โค้ดนี้ใช้ Guilds, GuildMessages และ GuildMessageReactions เท่านั้น จึงไม่ต้องเปิด Message Content Intent, Server Members Intent หรือ Presence Intent

## 2. เติม Token และ ID

เปิด Discord > User Settings > Advanced > Developer Mode จากนั้นคลิกขวาเซิร์ฟเวอร์และห้อง เลือก Copy Server ID / Copy Channel ID สำหรับยศเปิด Server Settings > Roles แล้วใช้ Copy Role ID

แก้ไฟล์ .env ที่เตรียมไว้:

```env
DISCORD_TOKEN=โทเคนบ็อตของคุณ
GUILD_ID=ไอดีเซิร์ฟเวอร์
CHANNEL_ID=ไอดีห้องรับยศ
```

แก้ config.json โดยเปลี่ยน roleId เป็น ID ยศจริง **เก็บ ID ไว้ในเครื่องหมายคำพูด** สามารถเพิ่มหรือลบรายการได้ (1–20 รายการ) ตัวอย่าง:

```json
{
  "title": "🎬 รับยศร้านไอฟิล์ม",
  "description": "กดอิโมจิด้านล่างเพื่อรับยศที่ต้องการ",
  "removeRoleOnUnreact": true,
  "roles": [
    { "emoji": "✅", "roleId": "123456789012345678", "label": "สมาชิก" }
  ]
}
```

ID ในตัวอย่างเป็นตัวเลขสมมติ ต้องเปลี่ยนให้ตรงกับเซิร์ฟเวอร์ของคุณ ใช้อิโมจิและยศไม่ซ้ำกันในแต่ละรายการ ถ้าต้องการรับยศแล้วเก็บไว้แม้เอาอิโมจิออก ให้เปลี่ยน removeRoleOnUnreact เป็น false

สำหรับอิโมจิที่สร้างเอง ใส่ `"emoji": "<:ชื่ออิโมจิ:ไอดีอิโมจิ>"` หรือ `"emoji": "ไอดีอิโมจิ"` แบบเคลื่อนไหวใช้ `<a:ชื่อ:ไอดี>` อิโมจิต้องอยู่ในเซิร์ฟเวอร์ที่ตั้งไว้

## 3. ติดตั้งและเปิดบ็อต

ใช้ Node.js 24.17.0 ขึ้นไป แล้วเปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์:

```powershell
npm.cmd install
npm.cmd run check
npm.cmd start
```

คำสั่ง check ตรวจเฉพาะรูปแบบการตั้งค่า ส่วนเมื่อ start จะตรวจยศและสิทธิ์กับ Discord ก่อนส่งข้อความ หากการตั้งค่าครบ บ็อตจะส่งข้อความใน CHANNEL_ID และแสดงลิงก์ในเทอร์มินัล

หลังติดตั้งส่วนประกอบแล้ว สามารถดับเบิลคลิก START-BOT.cmd เพื่อเปิดบ็อตได้เช่นกัน

เปิดหน้าต่างโปรแกรมไว้เพื่อให้บ็อตทำงาน หยุดด้วย Ctrl+C ถ้าต้องการออนไลน์ตลอดเวลาให้นำไปรันบนเครื่องที่เปิดตลอดหรือบริการโฮสต์

## การปรับแต่งและข้อจำกัด

- แก้ config.json แล้วปิดและเปิดบ็อตใหม่ ข้อความเดิมจะอัปเดตและเพิ่มอิโมจิที่ตั้งไว้
- เก็บ data/panel.json ไว้ หากลบไฟล์นี้บ็อตจะสร้างข้อความใหม่
- อิโมจิที่เลิกใช้แล้วอาจยังอยู่บนข้อความเดิม บ็อตจะไม่แจกยศให้อิโมจินั้น สามารถลบอิโมจิเก่าเองได้
- ยศที่สมาชิกได้รับไปแล้วจะไม่ถูกเปลี่ยนย้อนหลังเมื่อแก้การจับคู่อิโมจิ
- เหตุการณ์กด/เอาอิโมจิออกขณะบ็อตออฟไลน์จะไม่ถูกย้อนประมวลผล เมื่อบ็อตกลับมาออนไลน์ให้เอาอิโมจิออกและกดใหม่เพื่อรับยศ
- การลบอิโมจิทั้งรายการ/ทุกอิโมจิโดยผู้ดูแลไม่ใช่การยกเลิกทีละสมาชิก จึงไม่ถอดยศย้อนหลังให้สมาชิกทั้งหมด
- ถ้าเปลี่ยนห้องหรือเซิร์ฟเวอร์ บ็อตจะสร้างข้อความใหม่ในตำแหน่งใหม่ ข้อความเก่าจะไม่ทำงานอีก
- ใช้บ็อตหนึ่งโปรเซสต่อโฟลเดอร์นี้

## ถ้ากดแล้วไม่ได้ยศ

ตรวจว่าใช้ข้อความตามลิงก์ที่บ็อตแสดง, บ็อตออนไลน์, ID ยศถูกต้อง, มีสิทธิ์ Manage Roles และยศบ็อตอยู่สูงกว่ายศที่แจก ยศของระบบ/บ็อตอื่นและ @everyone แจกด้วยวิธีนี้ไม่ได้ ตรวจข้อความข้อผิดพลาดในหน้าต่างบ็อตด้วย
